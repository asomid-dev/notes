
Divide and conquer solves a problem in 3 steps:
1. Dividing it into subproblems
2. Recursively solving the subproblems
3. Combining the answers in the right way

Divide and conquer algorithms usually follow a uniform strategy.
A problem of size n is solved:
- Dividing it into a subproblems of size n/b and
- combining the answers

Where a >= 1, b > 1 and the cost of dividing into subproblems + combining the answers is $\Theta(n^k)$ for k > 0.

In this situation, the cost can be expressed with the recurrence:
$$T(n)=a \times T\left( \frac{n}{b} \right) + \Theta(n^k)$$
which can be solved using master theorem II.

## Master Theorem II

$$
T(n)=\begin{cases}
f(n), \qquad \qquad\qquad if \; 0\leq n < n_{0} \\
a \times T\left( \frac{n}{b} \right) + g(n), \;if \; n \geq n_{0} 
\end{cases}$$

where $n_{0} \in \mathbb{N}, b>1, f$ is an arbitrary function and $g \in \Theta(n^k)$ for $k\geq 0$.
Let $\alpha = \log _{b} (a).$ Then,

$$T(n) \in \begin{cases}
\Theta(n^{k}), \qquad \quad \;if \; \alpha < k\\
\Theta(n^{k}\log n), \quad if \; \alpha = k\\
\Theta(n^{\alpha}), \qquad \quad if \;\alpha > k
\end{cases}$$


```cpp
int binary_Search(const vector<int>& a,int i,int j,int x)
{   if (i <= j) {
		int k = (i + j) / 2;
		if (x < a[k])
			return binary_search(a, i, k-1, x);
		else if (x > a[k])
			return binary_search(a, k+1, j, x);
		else
			return k;
	}
	else return -1;
}
```
The parameter of recursion is $n=j-i+1$ and the cost $T\left( \frac{n}{2} \right)+\Theta(1)$
Using master theorem II, $T(n) \in \Theta(\log n)$.

## 2.1 Merge Sort

## 2.1.1 Basic merge algorithm
_Mergesort_ is a good example of a divide and conquer algorithm. It uses almost optimal number of comparisons and it is stable in the following sense: 
- It preserves the order between equal elements

The main operation combines (or merges) two sorted vectors into one. Given a vector $T$ of size $\geq 2$, the algorithm:
1. Splits the vector into two halves
2. Recursively sorts the first half of $T$
3. Recursively sorts the second half of $T$
4. Returns the fusion of both halves

```cpp
template <typename elem>
void mergesort (vector<elem>& T) {
	mergesort(T, 0, T.size() - 1);
}
template <typename elem>
void mergesort (vector<elem>& T, int e, int d) {
	if (e<d) {
		int m = (e + d) / 2;
		mergesort(T, e, m);
		mergesort(T, m + 1, d);
		merge(T, e, m, d);
} }
```

The algorithm's core is merging 2 sorted vectors.

```cpp
template <typename elem>
void merge (vector<elem>& T, int e, int m, int d) {
	vector<elem> B(d - e + 1);
	int i = e, j = m + 1, k = 0;
	while (i <= m and j <= d) {
		if (T[i] <= T[j]) B[k++] = T[i++];
		else              B[k++] = T[j++];
	}
	while (i <= m) B[k++] = T[i++];
	while (j <= d) B[k++] = T[j++];
	for (k = 0; k <= d-e; ++k) T[e + k] = B[k];
}
```

> [!warning] Observation: 
> After every comparison, we add an element to the table $B$, the last one, adds at least 2.

```cpp
template <typename elem>
void mergesort (vector<elem>& T, int e, int d) {
	if (e<d) {
		int m = (e + d) / 2;
		mergesort(T, e, m);
		mergesort(T, m + 1, d);
		merge(T, e, m, d);
} }
```

As merge procedure is linear, the cost of merge can be expressed with the recurrence
$$T(1)=\Theta(1)$$
$$T(n)=2T\left( \frac{n}{2} \right)+\Theta(n) \quad for \; n>1$$

This merge sort is for small vectors

## 2.1.2 Variants

### Iterative mergesort 1:

Version from the book _Algorithms by Dasgupta/Papadimitriou/Vazirani in pseudocode (pg 51). It uses an abstract data type queue with operations_
- inject(Q,e): adds element e to the queue Q
- eject(Q): removes and returns the last element in Q

```cpp
function mergesort_queue(a[1...n])
	Q = [] // (empty queue)
	for i=1 to n:
		inject(Q, a[i])
	while |Q| > 1:
		inject(Q, merge(eject(Q), eject(Q)))
	return eject(Q)
```

## 2.2 Quicksort

### 2.2.1 General Algorithm
As it name indicates, QuickSort is the quickest generic sorting algorithm.

Even though its worst-case is $\Theta(n^2)$, avg case is $\Theta(n \log n)$

Given a vector $T$ with at least 2 elements, the basic algorithm does the following:
- Choose an element $x$ in $T$
- Divide $T$ in 2 disjoint groups:
	- $T_{1},$ containing elements $\leq x$ in $T$
	- $T_{2}$, containing elements $\geq x$ in $T$
- Sort $T_1$ and $T_2$ recursively
- Return $T_1$ followed by $T_2$

template <typename elem>
int partition (vector<elem>& T, int e, int d) {
	elem x = T[e];
	int i = e - 1;
	int j = d + 1;
	for (;;) {
		while (x < T[--j]);
		while (T[++i] < x);

} }

## 2.2.2 Variants

We consider 3 strats for choosing the pivot:

1. Choose the first element
	- Acceptable if input is random
	- If iput is sorted, alogorithm takes $\Theta(n^2)$
2. Choose a random element
	- safe choice to divide into similar subproblems
	- the cost of generating random numbers may be significant
3. Choose the median of 3 elements
	- the best option would be to choose the median of the vector is too expensive
	- a good estimation is to use the median of 3, usually the 1st, the one in the middle and last one.

## 2.2.3 Analysis
> [!info] Recurrence
> Let $T(n)$ be the cost of quicksort on $n$ elements
> Then for $n\geq 2$
> $$T(n)=T(i)+T(n-i)+\Theta(n)$$
> Where $i$ is the number of elements of the first half, and $n-i$ the second.

### Analysis: General case:
$$ T(n) = T (i) + T (n − i) + Θ(n)$$

### Analysis: Worst case: 
$$T (n) = T (n − 1) + Θ(n)$$
Resolving the recurrence (directly or by master THM II), we obtain:
$$T(n) \in \Theta(n^2)$$

### Analysis: Best case: 

In the best case the pivot is the median of vector and both subvectors have the same size.
$$T (n) = 2T (n/2) + Θ(n)$$
It is the same recurrence as for mergesort, Hence, its cost is:
$$T(n)\in \Theta(n \log n)$$

### Analysis: Average case:
For the avg case, we assume that the partition is random and hence, each one has probability 1/n. The average value of T(i) and T(n-i) will be of $\frac{1}{n-1} \sum^{n-1}_{j=1}T(j)$.

Let c be a constant
$$T(n)=\frac{2}{n-1} \left[ \sum^{n-1}_{j=1}T(j) \right] + cn \tag 1$$

We multiply equation 1 by $n - 1$:
$$(n - 1)T(n) = 2 \left[ \sum_{j=1}^{n-1} T(j) \right] + cn(n - 1). \tag{2}$$

To eliminate the summation, we write the case for $n + 1$:
$$nT(n + 1) = 2 \left[ \sum_{j=1}^{n} T(j) \right] + c(n + 1)n \tag{3}$$

and subtract equation (2) from (3):
$$nT(n + 1) - (n - 1)T(n) = 2T(n) + 2cn. \tag{4}$$


Rearranging the terms,
$$nT(n + 1) = (n + 1)T(n) + 2cn. \tag{5}$$

We divide equation (5) by $n(n + 1)$:
$$\frac{T(n + 1)}{n + 1} = \frac{T(n)}{n} + \frac{2c}{n + 1}. \tag{6}$$

We substitute $n$ for all values from $n - 1$ down to 1:
$$\frac{T(n)}{n} = \frac{T(n - 1)}{n - 1} + \frac{2c}{n}. \tag{7}$$

$$\frac{T(n - 1)}{n - 1} = \frac{T(n - 2)}{n - 2} + \frac{2c}{n - 1}. \tag{8}$$
$$\vdots$$
$$\frac{T(2)}{2} = \frac{T(1)}{1} + \frac{2c}{2}. \tag{9}$$

The sum of all equations (7)–(9) gives:
$$\frac{T(n)}{n} = \frac{T(1)}{1} + 2c \sum_{i=2}^{n} \frac{1}{i}. \tag{10}$$

On the other hand, it is known that:
$$\sum_{i=2}^{n} \frac{1}{i} = \ln(n) + \gamma - 1,$$

where $\gamma \approx 0.577$ is the Euler–Mascheroni constant.

Substituting this value into equation (10) obtained earlier,
$$\frac{T(n)}{n} = \frac{T(1)}{1} + 2c \sum_{i=2}^{n} \frac{1}{i}$$

it follows that:
$$\frac{T(n)}{n} \in \Theta(\log n)$$

and, therefore,
$$T(n) \in \Theta(n \log n).$$

## Karatsuba's Algorithm

Carl Friedrich Gauss found out that even though the product of 2 complex numbers
$$(a+bi)(c+di)=ac-bd+(bc+ad)i$$
seems to need 4 products of real numbers, it can be obtained with only 3. The reason is that
$$bc+ad=(a+b)(c+d)-ac-bd$$

Let us assume that x and y are two integers of n bits. We can express x,y in two parts:

$$x= X_E \; x_D = 2^{[n/2]}x_E+x_D$$
$$y= y_E \; y_D = 2^{[n/2]}y_E+y_D$$

Example: if x = 10010111_2 and y=11001010_2 then
$$x = x_{E \;}x_D = 1001_2 \; 0111_2$$
$$y = y_E y_D = 1100_2 \; 1010_2$$

Now the product
$$xy = (2n/2xE + xD ) (2n/2yE + yD )$$
where n is even can be rewritten as
$$xy = 2^{n}x_{E} y_{E} + 2^{{n}/{2}}(x_{E} y_{D} + x_{D} y_{E} ) + x_{D} y_{D}$$
and when n is odd as: (n-1)
$$xy = 2^{n-1}xE yE + 2^{{n-1}/{2}}(xE yD + xD yE ) + xD yD$$

An algorithm based on this expression has a cost of
$$T (n) = 4T (n/2) + Θ(n)$$

## Strassen's Algorithm 
The obvius iterative algorithm for computing x^n uses the decomposition
$$x^n = x · x · ... · x \quad(n \;factors)$$
that performs $\Theta(n)$ multiplication

With a recursive approach we have that 
$$x^n = (x^{n/2})^2$$
when n is even and
$$x^n · x = (x^{(n-1)/2})^2 · x$$
when n is odd

Base case: x^0 = 1

Quick exponentiation
```cpp
double potencia (double x, int n) {
	if (n == 0) {
		return 1;
	} else {
		double y = potencia (x, n / 2);
		if (n % 2 == 0) return y * y;
		else return y * y * x;
} }
```

The cost of computation is easy
$$T (n) = T (n/2) + Θ(1)$$
that, according to master theorem II, implies
$$T (n) ∈ Θ(log n).$$

The product of two matrices $n \times n$ $X$ and $Y$ is a matrix $n \times n$ $Z$ such that
$$Z_{ij}=\sum^{n}_{k=1}X_{ik}Y_{kj}.$$
We can think of $Z_{ij}$ as the product of the $i$-th row of $X$ by the $j$-th column of $Y$

The formula, computed for each i,j between values i,j = 1...n implies an algorithm $\Theta(n^3)$

Strassen creates this algorithm of cost $\Theta(n^{\log_{2} 7}) \approx \Theta(n^{2.81})$

```cpp
matrix<int> producte_matrius
		(const matrix<int> & a, const matrix<int> & b)
{
	int n = a.numrows();
	matrix<int> c(n, n);
	int i;
	for (i = 0; i < n; i++)
		for (int j = 0; j < n; j++)
			c[i][j] = 0;
		for (i = 0; i < n; j++)
			for (int j = 0; j < n; j++)
				for (int k = 0; k < n; k++)
					c[i][j] += a[i][k] * b[k][j];
	return c;
}
```
