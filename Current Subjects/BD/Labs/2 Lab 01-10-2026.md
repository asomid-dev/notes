# Subconsultes en sentències Delete, Update i Select

- Poden apareixer en aquelles sentències on hi ha la clàusula **`WHERE`** 

- Esborrat de files d'una taula:   
```sql
delete from <table_name>
where ... (select ....);
```

- Modificació de files d'una taula
```sql
update <table_name>
set ...
where ... (select ....);
```

- Consultes una taula o més taules
```sql
select <columns>
from <table_names>
where ... (select ....);
```

### Exemples:

> [!example] DELETE
> ```sql
> delete from projectes
> where not exists (
> 	select*
> 	from empleats e
> 	where e.num_proj = projectes.num_proj
> );
> ```

> [!example] UPDATE 1
> ```sql
> update projectes
> set pressupost = pressupost + (pressupost * 0,1)
> where 2 <= (
> 	select count(*)
> 	from empleats e
> 	where projectes.num_proj = e.num_proj
> );
> ```

> [!example] UPDATE 2
> ```sql
> update empleats
> set sou = (
> 	select avg(e2.sou)
> 	from empleats e2
> 	where e2.num_dpt = 1
> )
> where num_dpt = 3;
> ```

> [!example] SELECT
> ```sql
> select e.num_empl, e.nom_empl
> from empleats e
> where e.sou > (
> 	select avg(e1.sou)
> 	from empleats e1
> );
> ```

# Subconsultes en sentències Insert i clàusules Having

- En aquelles sentències on hi ha la clàusula **`HAVING`**:
```sql
select <columnes_a_seleccionar>
from <taules_a_consultar>
where <condicions>
group by <columnes_agrupació>
having ..... (select ..... );
```

- Finalment, en sentències d’inserció de files a una taula (en aquest cas el resultat de la subconsulta és un conjunt de files que ha de ser compatible amb la definició de la taula en el **`CREATE TABLE`**)
```sql
insert into <table_name>
(select ....);
```

> [!example] HAVING
> ```sql
> select d.num_dpt, d.nom_dpt, 100*SUM(e.sou)/d.pressupost as percSous
> from departaments d, empleats e
> where d.num_dpt = e.num_dpt
> group by d.num_dpt
> having sum(e.sou) > ( 
> 	select sum(e1.sou)
> 	from empleats e1
> 	where e1.num_dpt = 3
 > );
> ```

> [!example] INSERT
> ```sql
> select e.num_empl, e.nom_empl
> from empleats e
> where e.sou > (
> 	select avg(e1.sou)
> 	from empleats e1
> );
> ```

# Tipus de dades (temps)

### 1. Els tipus de dades principals

Quan creues una taula amb dates, utilitzaras bàsicament aquests tres tipus:

- **`DATE`**: Només guarda la data (any, mes, dia). Exemple: `'2026-06-15'`.
- **`TIMESTAMP`**: Guarda la data i l'hora exacta (fins i tot amb mil·lisegons). Exemple: `'2026-06-15 14:30:00'`.
- **`INTERVAL`**: Representa un període de temps (dies, hores, mesos...). S'utilitza per sumar o restar temps.

### 2. Funcions per obtenir la data i l'hora actual

Si necessites comparar o inserir la data del sistema en el moment de la consulta:

- `CURRENT_DATE`: Retorna només la data d'avui.
- `CURRENT_TIMESTAMP` o `NOW()`: Retorna la data i l'hora actuals.

### 3. Operacions amb dates (Sumar i restar)

A PostgreSQL pots sumar o restar dies, mesos o hores directament utilitzant la paraula clau **`INTERVAL`**.

- **Afegir 30 dies a una data:**
```sql
select data_inici + interval '30 days' 
from projectes
```
- **Restar 2 mesos:**
```sql
select data_inici - interval '2 months' 
from projectes
```

- **Restar dues dates:** Si restes una data d'una altra, PostgreSQL et calcula automàticament els dies que han passat (et retorna un `INTERVAL`.
```sql
select data_fi - data_inici as dies_totals 
from projectes
```

### 4. Extreure parts d'una data (`EXTRACT`)

Molt útil si vols filtrar per un mes específic, un any o un dia de la setmana. S'utilitza la funció `EXTRACT`:

```sql
SELECT EXTRACT(YEAR FROM data_inici) AS any_inici
FROM projectes;
```

_Altres opcions que es poden posar dins del `EXTRACT`:_ `MONTH`, `DAY`, `HOUR`, `DOW` (dia de la setmana del 0 al 6).

> [!problem] PROBLEMA 1: Doneu una sentència SQL per obtenir el nom dels empleats que guanyen el sou més alt. Cal ordenar el resultat **descendenment** per nom de l'empleat.  
> 

> [!check] SOLUCIÓ 1: 
> ```sql
> select distinct nom_empl
> from empleats
> where sou = (
> 	select MAX(sou)
> 	from empleats
> )
> order by nom_empl desc;
> ```

> [!problem] PROBLEMA 2: Doneu una sentència SQL per obtenir els números i els noms dels projectes que tenen assignats dos o més empleats.  Cal ordenar el resultat **descendement** per número de projecte.
> 

> [!check] SOLUCIÓ 2:
> ```sql
> select distinct p.num_proj, p.nom_proj
> from projectes p
> inner join empleats e on p.num_proj = e.num_proj
> group by p.num_proj, p.nom_proj
> having count(e.num_empl) >= 2
> order by p.num_proj desc;
> ```

> [!problem] Doneu una sentència SQL per incrementar en 500000 el pressupost dels projectes que tenen algun empleat que treballa a BARCELONA.  

> [!check] SOLUCIÓ 3:
> ```sql
> update projectes p
> set pressupost = pressupost + 500000
> where p.num_proj IN (

> 	from empleats e

> );
> ```

> [!problem] PROBLEMA 5: Doneu una sentència SQL per obtenir els vols problemàtics de la base de dades donada.
> 
> Es vol obtenir el codi, la data de sortida, l'any del vol, el mes del vol i el retard que s'ha produit. Tingueu en compte el següent:
> - Els vols problemàtics són els vols de la taula _vols_ que la seva data de sortida sigui a partir del juny i que hagin tingut un retard de més d'un dia (24 hores).
> - Per obtenir un TIMESTAMP a partir de una DATE i un TIME es pot fer sumant aquests dos últims valors.
> - El resultat ha d'estar ordenat per codi de vol i data de sortida.

> [!check] SOLUCIÓ 5
> ```sql
> select      codi vol,
> 		   data_sortida,
> 		   extract(year from data_sortida) as any_vol
> 		   extract(month from data_sortida) as mes_vol
> 		   (moment_enlairament - (data_sortida +  hora_sortida_prevista)) as retard
> from        vols
> where       extract(month from data_sortida) >= 6
> 		   and (moment_enlairament - (data_sortida + hora_sortida_prevista)) > interval '1 day'
> order       by codi_vol, data_sortida;
> ```
