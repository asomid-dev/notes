# 1. Vectorial Subspace
#m1 #linearAlgebra 
$$\mathbb{R}^n = \left\{\begin{pmatrix}x_{1} \\  x_{2} \\ \vdots \\ x_{n} \end{pmatrix} :x_{i}\in \mathbb{R},1\leq i\leq n\right\}$$

Let $x=(x_{1},\dots,x_{n})$ and $y=(y_{1},\dots,y_{n})$ two elements of $\mathbb{R}^{n}$, and $\lambda \in \mathbb{R}$ a scalar:

1. **Addition:** $x+y=(x_{1}+y_{1},\dots,x_{n}+y_{n})$
2. **Scalar multiplication:** $\lambda x=(\lambda x_{1},\lambda x_{2}, \dots,\lambda x_{n})$

A vector space over a field $\mathbb{K}$ (normally $\mathbb{R}$), is a non-empty set E with an internal operation (addition) and an external operation (scalar multiplication) that satisfy 8 axioms:

### Addition axioms:
* **e1 Associative:** $u+(v+w)=(u+v)+w$
* **e2 Commutative:** $u+v=v+u$
* **e3 Identity element:** $\exists! 0_{E} \in E:u+0_{E}=u$ example: $(x,y)+(0,0)=(x,y)$
* **e4 Inverse element:** $\forall u, \exists!(-u):u+(-u)=0_{E}$

### Multiplication axioms:
* **e5 Associative:**$\lambda(\mu u)=(\lambda \mu)u$
* **e6 Distributive over vector addition:** $\lambda(u+v)=\lambda u+\lambda v$
* **e7 Distributive over scalar addition:** $(\lambda+\mu)u=\lambda u+\mu u$
* **e8 Multiplicity identity:** $1\times u=u$

### Vector spaces examples:
* **Matrius $\mathcal{M}_{m\times n}(\mathbb{K})$
* **Polynomials $\mathcal{P}(\mathbb{R})$**
* **Trivial space {$0_E$}**
* **Solutions of a linear system:** The solution set of $Ax=0$ always creates a vector space.

### Basic properties

If $v\in E \text{ and } \lambda \in \mathbb{K}$ always satisfy:
1. $0·v=0_{E}$
2. $\lambda · 0_{E} = 0_{E}$
3. If $\lambda v=0_{E}$, then $\lambda=0$ or $v=0_{E}$
4. The inverse element of $v$ is $(-1)v$. Normally we express it as $-v$.

# 2. Linear combination and vector subspaces (V.S.S.)

### 2.1 Linear combination
Imagine that the ingredients are $\vec{v}$ and $\vec{w}$ (vectors) and numbers: $\lambda = 2$ and $\mu = 3$ (scalars). The linear combination is the final dish: $2\vec{v}+3\vec{w}.$

Given the vectors: $u_{1},\dots,u_{k} \in E$, a linear combination of these vectors is any expression of the form: $v=\lambda_{1}u_{1}+\lambda_{2}u_{2}+\dots+\lambda_{k}u_{k}$ where the $\lambda_{i}$ are scalars.

### 2.2 Vector Subspace
A **subspace** is a subset of a vector space that behaves exactly like the original space. It is a universe within a universe that preserves the same "physics" (the operations of addition and scalar multiplication). This subset is autonomous: if you restrict yourself to operating with its vectors through linear combinations, you can never escape it.

For this to be possible, there are two requirements:

- **The origin must be in it:** You cannot have a universe without a coordinate center, (0,0,0).
- **The structure must be flat:** Any curvature or finite boundary would cause you to escape into the outer space when stretching a vector. Because of this, subspaces are always lines, planes, or hyperplanes that pass through the origin.

**Formal definition:**
Formally, a non-empty subset $S⊆E$ is a **subspace** (or vector subspace) if it itself has the structure of a vector space under the same operations as E. In practice, you only need to verify that it is **closed under linear combinations** by checking three conditions:

1. **It contains the zero vector:** $0_{E}​∈S$. (If the zero vector is not there, you immediately know it is not a subspace).
2. **Closed under addition:** $\forall u,v∈S⟹u+v∈S$.
3. **Closed under scalar multiplication:** $\forall u∈S \text{ and } λ∈K⟹λu∈S.$

### 2.3 Linear Independence 
A set of vectors {$u_{1},\dots,u_{k}$} is LI if each one brings new information. If a vector were linearly dependent (LD), it would mean that it is "redundant" because you could build it by combining the others. For example: 

* **LI:** $u=(1,0)$ and $v=(0,1).$ There is no way to multiply (1,0) by a number to get (0,1). They point in completely different directions.
* **LD:** $u=(1,2)$ and $v=(2,4).$ Here, $v=2u$. The vector v tells us nothing new; it is just the vector $u$ stretched out. It is redundant.

We have 3 methods for knowing if a set is LI or LD:

### Method 1: The Fundamental Equation (Definition)
Based on the definition, we set up the equation:

$$\lambda_{1}u_{1} + \lambda_{2}u_{2} + \dots + \lambda_{k}u_{k} = 0_{E}$$

- If the **only** solution is the trivial one ($\lambda_{1} = \dots = \lambda_{k} = 0$) $\implies$ **LI**.
- If we find any other combination $\implies$ **LD**.

**Example (Polynomials):** Are $p_{1} = x + 1$ and $p_{2} = x - 1$ independent?

$$\lambda_{1}(x + 1) + \lambda_{2}(x - 1) = 0 \implies (\lambda_{1} + \lambda_{2})x + (\lambda_{1} - \lambda_{2}) = 0$$

Solving the system:
$$\begin{cases} \lambda_{1} + \lambda_{2} = 0 \\ \lambda_{1} - \lambda_{2} = 0 \end{cases}$$

We obtain $\lambda_{1} = 0$ and $\lambda_{2} = 0$. Therefore, they are **LI**.

### Method 2: The Rank (For vectors in $\mathbb{R}^n$)
If we have numerical vectors, the fastest way is to place them as columns in a matrix $A$ and calculate its rank ($r$).

- If $r = \text{number of vectors} \implies$ **LI**.
- If $r < \text{number of vectors} \implies$ **LD**.

**Example:** For $u = (1, 0, 1)$, $v = (0, 1, 1)$, and $w = (1, 1, 2)$, the rank of the matrix is $2$ (because $w = u + v$). Since we have $3$ vectors but the rank is $2$, the set is **LD**.

### Method 3: Solving Systems of Equations (CDS / CIS)
When we set up the fundamental equation as a homogeneous system of linear equations ($Ax = 0$):

- If the system is a **Consistent Determinate System (CDS)** $\implies$ the only solution is the zero solution $\implies$ **LI**.
- If the system is a **Consistent Indeterminate System (CIS)** $\implies$ there are infinite possible combinations $\implies$ **LD**.

### 2.4 Subspace Spanned by a Set
The **span** of a set of vectors $\{u_{1},\dots,u_{k}\}$, denoted by $\langle u_{1},\dots,u_{k}\rangle$ or $\text{span}(u_{1},\dots,u_{k})$, is the set of all their possible linear combinations. 

It is the smallest vector subspace that contains these vectors, and the set $\{u_{1},\dots,u_{k}\}$ is called a **spanning set** for this subspace.

### 2.5 Operations with Subspaces
When we have two subspaces $S$ and $W$ (two mini-universes), we can try to combine them. However, not all combinations respect the "laws of physics" of vector spaces.

#### 1. Intersection ($S \cap W$)
The intersection is the set of vectors that belong to both universes at the same time.

- **Intuition:** If you have two planes passing through the origin, their intersection is the line where they cross. Since both planes are "stable" (closed), the ground they share is also stable.
- **Golden Rule:** The intersection of subspaces is **ALWAYS** a vector subspace.



#### 2. Union ($S \cup W$)
Trying to combine two subspaces by simply "joining them together" (like putting two stickers side by side) does not work.

- **Intuition:** Imagine two lines (the X-axis and the Y-axis). The union consists *only* of the points that lie directly on the axes. But if you add the vector $(1,0)$ from the X-axis and $(0,1)$ from the Y-axis, you get $(1,1)$, which is in the middle of the plane and outside the axes. You have escaped the "club"!
- **Conclusion:** The union is **NOT** normally a subspace.

#### 3. Sum ($S + W$): The Expansion
Since the union fails, the sum is the correct solution to merge subspaces. It consists of taking all possible sums between a vector from $S$ and a vector from $W$:
$$S + W = \{s + w \mid s \in S, w \in W\}$$

- **Intuition:** It is like taking two lines and "filling in" all the space between them until they form a complete plane. The sum is always a subspace (the smallest one containing both $S$ and $W$).
- **In Practice:** To find a basis for $S + W$, we combine the spanning sets (generators) of $S$ and $W$, place them in a matrix, and eliminate the redundant (dependent) ones using row reduction.



#### 4. Direct Sum ($S \oplus W$): Absolute Independence
We say that the sum is a **direct sum** if the two universes only touch at the zero vector ($S \cap W = \{0_E\}$).

- **Intuition:** This is the "cleanest" merger possible. It means that every vector in the resulting space can be written in a **unique way** as a part from $S$ and a part from $W$. There is absolutely no redundancy.


# 3. Bases and Dimension

### Basis
A set of vectors $B = \{u_{1},\dots,u_{n}\}$ is called a **basis** of a subspace $S$ if and only if:
$$\text{rank}(M_{B}) = n = \dim(S)$$

This means the set must satisfy two conditions:
1. It must be **Linearly Independent (LI)**.
2. It must be a **Spanning Set (Generator)** of $S$.

### Dimension
The **dimension** ($\dim E$) is the number of vectors contained in any of its bases.

| Space | Dimension |
| :--- | :--- |
| $\mathbb{R}^n$ | $n$ |
| $\mathcal{M}_{m \times n}(\mathbb{K})$ | $m \cdot n$ |
| $\mathcal{P}_d(\mathbb{R})$ | $d + 1$ |
| Trivial subspace $\{0_E\}$ | $0$ |
### Grassmann's Formula

Essential for problems involving sums and intersections: 
$$\dim(S + W) = \dim S + \dim W - \dim(S \cap W)$$

Let there be $k$ vectors in a space $E$ of dimension $n$:

1. **$k > n$:** The set is **always LD** (there are redundant vectors).
2. **$k < n$:** The set **cannot span $E$** (there are not enough vectors).
3. **$k = n$:** If you prove they are **LI** (or that they span), they are automatically a **Basis**. (This saves you half the work!).

### 4. Coordinates and Change of Basis

Every vector $v$ can be uniquely expressed in a basis $B$ using its coordinates $v_B$. The change of basis matrix $P_{B}^{B'}$ relates them:

$$v_{B'} = P_{B}^{B'} \cdot v_{B}$$
### Change-of-Basis Example

Let the standard basis be $E = \{(1,0), (0,1)\}$ and a custom basis be $B = \{(1,2), (0,1)\}$.

#### 1. Building the Matrix ($P_B^E$)
To go from $B \to E$, place the vectors of $B$ directly into the columns:
$$P_B^E = \begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix}$$

#### 2. Transforming $v_B \to v_E$
Given a vector with coordinates $v_B = \begin{pmatrix} 3 \\ -1 \end{pmatrix}$:
$$v_E = P_B^E \cdot v_B = \begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix} \begin{pmatrix} 3 \\ -1 \end{pmatrix} = \begin{pmatrix} 3 \\ 5 \end{pmatrix}$$

#### 3. Reverse Transformation ($P_E^B$)
To go backward from $E \to B$, invert the matrix:
$$P_E^B = (P_B^E)^{-1} = \begin{pmatrix} 1 & 0 \\ -2 & 1 \end{pmatrix}$$
$$v_B = P_E^B \cdot v_E = \begin{pmatrix} 1 & 0 \\ -2 & 1 \end{pmatrix} \begin{pmatrix} 3 \\ 5 \end{pmatrix} = \begin{pmatrix} 3 \\ -1 \end{pmatrix}$$
