# 📚 University Notes & Study Guides

Welcome to my personal digital garden! This repository contains my course notes, lecture summaries, and study materials organised directly from my **Obsidian** vault.

---

## ⚠️ Note on GitHub Preview
Because these notes are structured for **Obsidian**, they make heavy use of native Obsidian features such as:
* **Wikilinks** (`[[Note Name]]`) for bidirectional note linking.
* Custom callouts, block references, and embedded elements.

As a result, some internal links or formatting may appear slightly broken or raw when viewing them directly through the GitHub web interface. For the best reading experience, I recommend cloning the vault and opening it directly inside Obsidian!
